# HTTP-proxy сервер (HTTP 1.0)
Простой многопоточный HTTP-proxy сервер, реализующий протокол HTTP 1.0. Каждое клиентское соединение обрабатывается в отдельном потоке.

## Особенности
- **HTTP 1.0 протокол** - поддержка базовых возможностей HTTP
- **Многопоточность** - каждый клиент в отдельном потоке
- **Автоматическая нормализация** - преобразует HTTP/1.1 запросы в HTTP/1.0
- **Проксирование заголовков** - корректная передача всех HTTP заголовков
- **Обработка ошибок** - понятные HTTP коды ошибок (400, 502 и др.)
- **Поддержка разных типов запросов** - GET, POST и другие методы

### Требования
- Компилятор GCC
- Библиотека pthreads
- Linux/Unix-подобная система
